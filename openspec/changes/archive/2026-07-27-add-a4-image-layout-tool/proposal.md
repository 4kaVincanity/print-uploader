## Why

用户需要一种简单、无需专业排版软件的方式，将最多九张图片按 3x3 网格排列到 A4 页面，并获得可直接打印的高分辨率成品。浏览器端工具可以让用户在本地完成上传、排序、预览和下载，同时避免图片被发送到服务器。

## What Changes

- 新增图片上传工作区，支持常见浏览器图片格式并限制最多九张图片。
- 新增固定 3 列 x 3 行的版面编辑器，支持拖拽调整图片顺序、删除和补充图片。
- 新增单张图片的缩放与位置调整，使用户能够控制铺满格子时的裁剪区域。
- 支持从指定空位添加图片，使首张成功导入的图片进入用户点击的格位。
- 新增页面边距与图片间距控制，默认均为 0 mm，使 3x3 图片网格铺满整张 A4 页面。
- 新增 A4 竖版效果预览，准确反映当前页面边距、格子间距、空位和图片裁剪。
- 新增 300 DPI A4 PNG 生成与下载，输出尺寸为 2480 x 3508 像素，并在下载后关闭确认弹窗。
- 图片处理全部在浏览器本地完成，不依赖服务端上传或持久化。

## Capabilities

### New Capabilities

- `image-layout-editor`: 图片导入、格式与数量校验、3x3 网格展示、拖拽排序、删除，以及单图缩放和位置调整。
- `a4-preview-export`: 配置 A4 页面边距和图片间距，按当前版面参数生成预览，并使用原始图片渲染和下载 300 DPI PNG 成品。

### Modified Capabilities

无。

## Impact

- 新建基于 Vue 3、TypeScript 和 Vite 的浏览器端应用界面。
- 使用 Pinia 管理图片、格位、裁剪参数和生成状态，使用 Element Plus 构建基础交互控件与反馈状态。
- 应用代码按页面、可复用组件、接口层、跨页面状态、工具函数、项目配置、构建资源、静态公共资源和全局样式分层组织。
- 引入兼容 Vue 的触屏与鼠标拖拽排序能力，以及基于 Canvas 的高分辨率图像合成能力。
- 浏览器内存和性能会受到原始图片尺寸、图片数量及导出画布大小影响，需要限制输入并妥善释放对象 URL 和 Canvas 资源。
- 不新增后端 API、数据库或图片存储服务。

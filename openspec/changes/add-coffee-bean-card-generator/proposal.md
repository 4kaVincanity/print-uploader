## Why

现有应用提供固定的 A4 九宫格排版，而咖啡烘焙还需要按统一视觉模板制作豆卡。需要在不影响原有工具的前提下，新增一个浏览器本地的豆卡页面，把繁体中文参数、品牌署名与可自由编排的插图组合成可预览、可下载的图片。

## What Changes

- 新增咖啡豆卡生成页面，并在原九宫格页面提供进入该页面的入口及返回原工具的路径。
- 新增正方形与 A4 直式两种豆卡模板，严格采用已提供参考图的留白、文案层级、黑色主文和红色风味文案。
- 新增繁体中文咖啡豆字段录入，并将输入即时映射到模板文字。
- 新增由 Express 提供的豆子资料库 API，读取和安全写回 `src/public/beans-data.json`，支持在页面中快速选择、创建、编辑与删除资料。
- 两种模板均支持本地上传多张插图；用户可在画布内拖拽、缩放并调整插图层级。
- 内置 `Libian.ttc`，使预览与 PNG 导出使用一致的隶变字体。
- 导出与当前模板和编辑状态一致的高分辨率 PNG。

## Capabilities

### New Capabilities

- `coffee-bean-card-editor`: 提供繁体中文咖啡豆字段录入、正方形/A4 模板切换以及参考图一致的实时卡片预览。
- `coffee-bean-illustration-layout`: 支持在任一豆卡模板中本地导入、拖拽、缩放、排序及删除多张插图。
- `coffee-bean-card-export`: 将当前模板、文字和插图以一致的高分辨率 PNG 导出，并反馈生成状态与错误。

### Modified Capabilities

- 无。

## Impact

- 受影响的前端区域：应用入口、现有 A4 九宫格页面的导航按钮、新增豆卡页面、独立 Pinia 编辑状态与 Canvas 渲染工具。
- 将新增 Express 服务、开发代理与 `beans-data.json` 的原子读写；生产环境由该服务同时提供 API 与静态前端文件。
- 将新增字体加载、模板坐标和插图图层变换数据；图片及数据继续只在当前浏览器会话中处理。
- 项目继续使用 Vue、Pinia、Element Plus 和 Canvas，并新增 Express；首版不包含账号体系，原九宫格功能保持可用。
